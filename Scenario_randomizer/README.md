# Scenario Randomizer v0.5.0

`molit_e2e`에서 실제 수집에 쓴 `morai-scenario-generator-v0.5.0`과 그 수집 어댑터를 정리한다. 고정된 MORAI K-City 지도, 도로 링크, 기준 코스를 사용하고, 랩마다 장애물·보행자·주변 차량의 배치와 행동 조건을 바꿨다. 생성기 패키지는 `0.5.0`을 명시하고, 수집 어댑터는 이 버전을 확인한 뒤 해당 패키지를 불러온다.

## 실제 수집에 사용한 배치

20랩 GT 배치는 `Normal` 난이도와 고속도로 `Follow` 프로필을 사용했다. 대회 샘플 장면의 복사본에 Ego만 남겨 불러오고, 생성기가 담당하는 장애물과 주변 교통을 따로 배치했다. 원본 K-City 구역 지도와 기준 경로는 [Expert Recovery](../Expert/README.md)와 일치하는지 확인했다.

| 구간 | 랩별로 바뀌는 요소 |
|---|---|
| 정적 장애물 구역 | 정적 장애물 1개의 모델, 경로 진행 위치, 좌우 오프셋과 방향. 우회 경로를 연결할 공간을 남기도록 구역 가장자리에는 여유를 뒀다. |
| 동적 장애물 구역 | 실제 Ego 기준 경로와 교차하는 횡단보도를 사용했다. 보행자 출발점과 보행 속도를 바꾸고 Ego 도착 예상 시각에 맞춰 횡단을 시작했다. |
| 로터리 | 순환차의 시작 위치와 차량 간 간격, 진입차의 활성화 지연을 샘플링했다. 순환 간격의 합은 로터리 한 바퀴 길이와 일치한다. |
| 고속도로 | 차로별 차량 수, 차량 간격, 속도 프로필을 바꿨다. 실제 속도는 선행차·곡률·제동 조건에 따라 달라졌다. |
| 터널 | 정적 장애물의 위치를 바꾸고 두 보행자 횡단을 정적 우회 구간과 떨어뜨려 배치했다. 터널 보행자 설정은 개발용 수집 프로필에 포함됐다. |

## 배치에서 실제 주행까지

1. **계획 저장.** seed, 사용한 모델 카탈로그, 지도·경로 및 코드 해시, 각 액터의 모델·초기 자세·경로, 발동·종료 조건을 기록했다. 재실행할 때는 확정된 `scenario.json`과 해시를 기준으로 삼았다. 같은 계획을 사용해도 시뮬레이터의 물리 궤적과 렌더링은 달라질 수 있다.
2. **실제 형상 확인.** 액터를 배치한 뒤 MORAI에서 읽은 장애물 형상으로 Expert의 우회 경로를 계산했다. 차량 외곽과 도로 경계, 장애물 여유를 검증하고, 막힌 터널 구간이 있거나 필요한 장애물이 경로 검사에서 빠지면 출발 전에 해당 배치를 제외했다. 승인된 우회 경로는 해당 랩에 고정했다.
3. **시뮬레이터 제어.** 로터리 차량은 MORAI의 기본 AI와 경로를 사용하고, 고속도로 차량은 승인된 경로를 따라 조향·가속·제동 명령으로 움직였다. 보행자는 지면에 배치한 뒤 MORAI의 보행자 제어로 움직였다. Expert는 Ego를 운전했다. 같은 공유 GT 소스에서 실제 차량·보행자 움직임을 기록했다.
4. **랩 승인.** 실제 Ego 완주, 예정된 액터의 움직임·보행자 반응, 액터 정리, 원본 GT의 정상 종료와 무결성을 확인했다. 실패 시도의 기록은 남기고 완료 랩 수에서 제외했다.

## 실제 MORAI 실행 기록

| 실행 | 확인한 결과 |
|---|---|
| 2026-10-20 물리 NPC 검증 | 서로 다른 seed에서 약 2.18 km씩 완주했다. 두 주행 모두 보행자 횡단과 Expert의 반응을 확인했다. 한 주행에서는 고속도로 NPC가 Ego에 반응해 **44.9 → 34.4 km/h**로 감속한 후 다시 가속했다. |
| 2026-10-20 `physical-20laps-02` | **GT 20랩 승인**, 실패 시도 10건 별도 보존. 조회 50 Hz, Actor GT 저장 20 Hz. 승인된 랩은 주행 기능·원본 무결성 검사와 MGEO 변환을 통과했다. 첫 승인 랩은 Ego 실측 **2,187.76 m**, Actor 응답 **5,400건**을 기록했다. 이 배치에서는 센서 파일을 수집하지 않았다. |
| 2026-10-23 후속 10 Hz 수집, seed `20263355` | Expert 완주 후 **53개 기능 검사** 통과. Actor 응답 **2,805건**, 저장 슬롯 누락 0건, 실측 약 **9.9993 Hz**. 해당 주행에서 후속 `sunny13` 센서 묶음 **1,879개**도 검사를 통과했다. |

20랩 배치의 실패 10건 중 5건은 유효한 우회 경로를 확보하지 못한 배치였다. 나머지는 NPC의 도로 링크 불일치, 충돌 뒤 NPC 경로 이탈, 로터리 이벤트 시간 초과, 출발 전 정적물 이동으로 기록됐다. 위 수집 결과에서 센서 프레임의 물리적 동기화와 학습 적합성은 별도 검증 항목으로 남았다.
