# DAgger 구현

`molit_e2e`의 DAgger 수집은 모델을 MORAI에서 주행시키고, 모델이 실제로 도달한 상태에서 [Expert Recovery](../Expert/README.md)의 경로 제안과 실제 복구 궤적을 기록하는 방식이다. 기록을 검수해 기존 학습 데이터에 추가하고, 갱신된 체크포인트를 다시 주행에 투입한다. 이 문서의 수치와 동작은 당시 `molit_e2e`에서 확인한 내용이다.

## 제어 구성

```mermaid
flowchart LR
    A["센서 관측"] --> B["MODEL 경로 제안"]
    C["공유 GT와 주행 정책"] --> D["EXPERT 경로 제안"]
    C --> E["개입 및 복귀 판정"]
    B --> E
    D --> E
    E --> F["선택 경로"]
    F --> G["공통 MPC와 UDP 송신"]
    G --> H["MORAI Ego"]
    H --> C
```

기존 learner는 전방 RGB·LiDAR와 Ego 속도·navigation을 받았다. 모델 소스 시각과 관측 ID를 보존하고, 실행 설정에 따라 모델의 `route` 또는 `waypoints` 출력을 지역 경로로 전달했다. 공통 MPC에 전달하는 모델 속도 프로파일은 0.25초 간격의 예측 waypoint 간 거리에서 계산했다. 교사는 같은 시점의 실제 Ego/world 상태와 주행 정책으로 경로를 만들었다.

경로 선택은 한 번에 하나의 제어권만 부여한다. 선택 경로, MPC 결과, 실제 UDP 송신을 에피소드·세대·경로·명령 식별자로 대응시켜 인수를 확정한다. UDP 기록이 증명하는 범위는 브리지의 송신이며, 차량 반응과 도로 이탈·충돌 여부는 별도 GT 기록으로 판단한다.

## 개입과 복귀

| 단계 | 구현 |
|---|---|
| `MODEL` | 모델 경로를 사용하면서 실제 횡오차·헤딩 오차와 횡방향 움직임, 경계까지의 여유, 모델 제안의 최신성과 기하 유효성을 검사한다. 관측 이탈 프로필에서는 횡오차 0.8 m 또는 헤딩 오차 10°를 개입 조건으로 사용했다. |
| `TAKEOVER_PENDING` | 현재 상태가 설정된 범위에 있고 교사 입력이 유효하면 교사 경로를 요청한다. 새 세대의 정상 MPC 결과와 일치하는 UDP 송신이 확인되어야 교사 인수가 확정된다. |
| `EXPERT_RECOVERY` / `EXPERT_STABILIZE` | 교사 경로로 조향과 속도를 복구한다. 복귀 기준은 개입 기준보다 엄격하다. 예시 프로필에서는 횡오차 0.15 m 이하, 헤딩 오차 2° 이하, 유효한 모델 경로와 교사 경로 사이의 근거리 평균 차이 0.20 m 이하를 확인했다. 최소 교사 주행 시간과 연속 안정 시간도 적용했다. |
| `HAND_BACK_PENDING` | 안정 조건이 지속되면 모델 경로를 요청한다. 복귀 직전에 조건을 잃으면 교사 주행을 계속하거나 인수를 다시 요청한다. 모델 경로의 새 송신이 확인되면 `MODEL`로 돌아간다. |
| 제동·중단 | GT 만료, 확인되지 않은 복구 구간, 위험 상태 또는 전환 시간 초과에서는 브레이크 유지나 에피소드 종료를 요청한다. 후속 운영 구성은 식별자가 맞는 교사 MPC fallback에 대해 브레이크를 유지하고 새 교사 경로·MPC·UDP 송신을 다시 확인한다. |

이 값들은 특정 시뮬레이션 실험의 설정이며 복구 성공 범위로 실측된 값은 아니다. 유효 설정은 실행별 `gate.json`과 `trial.json`에 기록했다. 전체 랩에서는 시작 전에 검증한 주행 경로를 이탈 판정 기준으로 고정했다. 정적 장애물 우회 궤적을 명목 코스와 비교해 정상 우회를 이탈로 오인하는 문제가 있었기 때문이다. 원래 코스 기준 진행 거리와 교사 경로 추종 오차도 각각 기록했다.

## 기록에서 학습 데이터까지

1. **관측·권한 기록.** RGB/LiDAR, 원본 GT와 피드백, 모델·교사 제안, 개입 사유, 경로 선택, MPC 결과와 UDP 송신을 관측 시각 및 식별자와 함께 저장한다. 기록 종료와 무결성을 확인하고, 실패 주변과 입력·권한이 끊긴 구간을 식별할 수 있게 보존한다.
2. **공간 경로 라벨.** 경로 선택 전에 기록한 교사 제안 중 해당 관측 시점에 이미 유효했던 경로를 관측 기준 좌표계로 변환한다. 25개 XY 지점과 실제 유효 구간 마스크를 사용한다. 모델이 운전 중인 관측도 그 시점의 교사 제안이 있으면 공간 경로 후보가 될 수 있다.
3. **시간 궤적 라벨.** 관측 기준 시각에서 `+0.25초`부터 `+2.00초`까지, 교사가 연속으로 운전한 실제 Ego 위치 8개를 목표로 사용한다. 모델 복귀, 리셋 또는 입력 공백이 이 구간에 걸친 관측은 완전한 시간 라벨에서 제외한다. 뒤늦게 시작한 복구 궤적은 앞선 관측에 붙이지 않는다.
4. **별도 속도 supervision.** 후속 구성은 액추에이터 출력이 없는 Expert MPC worker에서 같은 관측과 교사 경로·정책으로 속도 라벨을 계산했다. 관측 ID와 입력 스냅샷 해시가 정확히 일치하는 결과만 결합하고, 입력 만료나 계산 실패는 유효성에 반영했다. 기존의 0 속도 자리표시자는 이 라벨에 포함하지 않았다. 이 라벨의 출처는 3단계의 실측 궤적과 구분한다.
5. **검수·재학습.** 유효한 센서와 보조 타깃, 물리적 복구 기록, 종료 및 원본 무결성 검사를 통과한 샘플을 버전이 있는 학습 데이터에 추가했다. 동일 시나리오에서 파생된 이벤트와 변형은 같은 데이터 분할에 두고, 갱신 모델을 다시 수집에 투입할 때 체크포인트와 실행 설정을 고정했다.

## 검증 결과와 한계

| `molit_e2e` 관측 | 확인한 결과 |
|---|---|
| 2026-10-24 첫 혼합 전체 랩 | 764.8 m에서 `EXPERT_RECOVERY_TIMEOUT`으로 중단했다. 원본 기록 무결성은 통과했으며 완주로 집계하지 않았다. |
| 초기 전체 랩 기준 경로 문제 | 정적 장애물 우회 중 원래 코스와의 차이는 1.548 m, 실제 교사 경로 추종 오차는 0.048 m였다. 이후 검증된 우회 경로를 이탈 판정 기준으로 고정했다. |
| 2026-10-27 후속 주행 | ROS `396c52c`를 사용한 모델 30 혼합 랩이 2,200.89 m를 주행하고 `LAP_COMPLETE_BRAKE`로 종료했다. 별도 시나리오에서는 복구 범위를 벗어나 중단한 사례가 남아 있다. |
| 재학습 연결 | 모델 21의 2,200.71 m 혼합 랩은 GT·보고서 아카이브의 파일 해시 검증을 통과했다. 이 소스에서 선별한 1,514개 행이 후속 학습에 편입됐고, 5 epoch 학습 완료가 기록됐다. |

완주와 재학습 연결은 과거 구성에서 확인했다. EvoDriveFlywheel의 camera-only TFv6에서는 입력 동기화, 개입·복귀 기준, 복구 라벨 유효성, 개선 효과를 별도로 검증해야 한다.
